# Samples de piano

O motor de som carrega os arquivos `.wav` desta pasta.

## Arquivos necessários

Coloque aqui os seguintes arquivos (oitava 4, teclas brancas):

- `C4.wav`
- `D4.wav`
- `E4.wav`
- `F4.wav`
- `G4.wav`
- `A4.wav`
- `B4.wav`

O motor usa esses 7 samples para todas as notas: notas em outras oitavas ou sustenidos são reproduzidas com alteração de taxa (playback rate).

## Onde obter samples

Você pode usar samples gratuitos, por exemplo:

- [Freesound](https://freesound.org/) (busque por "piano single note")
- [Philharmonia Orchestra](https://philharmonia.co.uk/resources/sound-samples/) (instrumentos por nota)

Formato: WAV, mono ou estéreo, qualquer taxa de amostragem (o navegador decodifica).
